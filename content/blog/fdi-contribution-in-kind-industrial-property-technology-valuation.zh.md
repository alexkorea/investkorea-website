可以。外国人投资促进法把外国投资者为持有股份等而出资的财产称为“出资标的物”，除外汇（对外支付手段）外，还规定了资本品、工业产权与技术、特定股票、韩国境内不动产，以及关闭韩国分支机构·办事处并转为法人时的剩余财产等。以实物出资时，关键在于由谁、如何确认价格；该法对资本品和工业产权设有替代商法程序的特例。

本文面向打算把海外总部的设备或专利出资给韩国法人的外国投资者，以及作为合资伙伴的韩国企业实务人员。

## 核心摘要

- 出资标的物：外汇等对外支付手段、资本品、股份等产生的收益、工业产权·知识产权·技术、关闭分支机构·办事处或法人解散时的剩余财产、借款等偿还额、特定股票、韩国境内不动产、股份·不动产处分价款
- 知识产权是指用于产业活动的著作权和半导体布图设计权；股票包括在外国证券市场上市的外国法人股票等
- 资本品实物出资时，关税厅长确认的实物出资完成确认书视为商法上检查人的调查报告
- 技术评估机构评估工业产权等价格时，视为商法上公认鉴定人的鉴定
- 为出资而进口的资本品可在进口申报受理前申请审查·确认，获确认即视为已取得进口批准
- 出资标的物缴纳完毕后须办理外国人投资企业登记，虚假缴纳进行的登记将被注销

## 1. 除现金外还可以用什么出资？

外国人投资促进法规定的出资标的物如下。

| 区分 | 内容 |
|---|---|
| 对外支付手段 | 外汇交易法规定的对外支付手段，或由其兑换产生的国内支付手段 |
| 资本品 | 作为产业设施的机械、器材、设施品、器具、零部件、附属品等 |
| 收益 | 依该法取得的股份等产生的收益 |
| 工业产权等 | 工业产权、总统令规定的知识产权、与之相当的技术及其使用权 |
| 剩余财产 | 关闭韩国分支机构·办事处转为国内法人，或国内法人解散时，清算后分配的剩余财产 |
| 偿还额 | 长期借款或其他海外借款的偿还额 |
| 股票 | 总统令规定的股票 |
| 不动产 | 位于韩国境内的不动产 |
| 处分价款 | 外国人持有的韩国法人·企业股份等及不动产的处分价款 |

资本品除船舶、车辆、飞机等产业设施外，还包括农业·林业·水产业发展所需的家畜、种子、树木、鱼贝类，被认定为首次试运行所需的原料·备品，以及引进时产生的运费·保险费和安装或咨询技术、劳务。

## 2. 哪些知识产权和股票可以出资？

施行令规定，可出资的知识产权是著作权法规定的著作权中用于产业活动的权利，以及半导体集成电路布图设计权。专利权等工业产权、与之相当的技术及其使用权，则由法律直接规定为出资标的物。

可出资的股票是在外国证券市场上市的外国法人股票，以及外国人依该法或外汇交易法持有的股票。非上市外国法人股票不在此列，需视个案确认。

## 3. 以机器·设备实物出资时，价格由谁确认？

依商法，实物出资原则上须经检查人调查。外国人投资促进法规定，外国投资者以资本品实物出资时，由关税厅长确认出资履行情况及标的物种类·数量·价格等的实物出资完成确认书，视为商法上检查人的调查报告。公司设立后以资本品实物出资时亦同。

申请实物出资完成确认时，须向关税厅长提交规定格式（附件第25号格式）的申请书2份。关税厅长通过行政信息共享确认进口申报证明，申请人不同意该确认时须附上该文件。完成确认后，关税厅长会通知韩国银行总裁。

## 4. 进口设备前要做什么？引进物品审查·确认

外国投资者作为出资标的物进口的资本品等，可接受主管部长官的审查·确认，经审查·确认的资本品等视为已取得对外贸易法规定的进口批准。

申请审查·确认时，须编制载明资本品数量·规格·价格·制造商等的引进物品明细表，并在进口申报受理前提出申请。该业务已委托给外汇银行行长和大韩贸易投资振兴公社社长，申请书（附件第24号格式）3份须附上物品销售确认书等证明价格的材料。

| 情形 | 申请期限 |
|---|---|
| 原则 | 进口申报受理前 |
| 依关税法缴纳关税时 | 自收到缴纳通知之日起5日内 |
| 物品尚未运出保税区时 | 自进口申报受理之日起15日内 |

## 5. 以专利·技术出资时如何评估价格？

总统令规定的技术评估机构评估工业产权等的价格时，其评估内容视为商法上公认鉴定人的鉴定。这里的技术评估机构是风险企业相关法令施行令规定的评估机构。具体哪些机构符合、评估需要多长时间，需视个案确认。

以股票、债券或韩国境内不动产出资时，办理外国人投资企业登记时须提交商法规定的检查人调查报告或鉴定人鉴定结果复印件。

## 6. 出资后如何办理外国人投资企业登记？

外国投资者或外国人投资企业在出资标的物缴纳完毕后，须办理外国人投资企业登记。登记申请时，按出资方式附上下列材料复印件。

- 实物出资以外的情形：可确认汇款人的外汇买入证明书或外汇存款证明书
- 以资本品出资：实物出资完成确认书
- 以股票、债券、韩国境内不动产出资：检查人调查报告或鉴定人鉴定结果
- 共同：法人登记事项证明书、股东名册、营业执照或固有编号证

以虚假缴纳出资标的物的方式办理外国人投资企业登记的，登记将被注销。虚报价格或把实际未转移的实物假装为已出资，可能使登记本身失效。

## 7. 常见问题

- 先办理设备通关，结果错过引进物品审查·确认的期限
- 只考虑商法上的检查人程序安排日程，没有办理实物出资完成确认
- 误以为非上市外国法人股票可以作为出资标的物
- 技术出资时未确认评估机构是否属于施行令规定的机构
- 韩国合资伙伴不了解出资标的物重估特例（以每月1日为重估日），按账面价值谈判

## 常见问题

### 海外总部的二手机器也可以出资吗？

作为产业设施的机械·器材等资本品属于出资标的物。关税厅长确认种类·数量·价格等的实物出资完成确认书可替代商法上检查人的调查报告。

### 以专利出资时由谁鉴定？

施行令规定的技术评估机构评估工业产权等价格时，视为商法上公认鉴定人的鉴定。

### 软件著作权也可以出资吗？

著作权法规定的著作权中用于产业活动的权利，属于可出资的知识产权。具体是否符合需视个案确认。

### 把韩国分支机构转为法人时，可以用分支机构财产出资吗？

外国人关闭韩国分支机构或办事处并转为其他国内法人时，清算后分配给该外国人的剩余财产属于出资标的物。

### 设备引进审查·确认最晚何时申请？

原则上在进口申报受理前。缴纳关税时自收到缴纳通知起5日内，未运出保税区时自进口申报受理之日起15日内可以申请。
