## 2026年外资法人在韩购置不动产的程序和注意事项

外资法人在韩国取得不动产，必须依法履行**依外国汇兑交易法向韩国银行申报**、**依外国人土地法进行取得申报**、缴纳取得税及办理登记等全部手续。此外，在调整对象地区取得住宅须缴纳12%重税，在土地交易许可区域取得不动产须事先取得政府许可。

本指南以2026年现行法规为基准，全面整理外资法人在韩取得不动产的5步程序、外商投资促进法（外资法）的注意事项、是否可经营租赁业及税务申报方法。

## 1. 外资法人的不动产取得申报义务

外资法人在韩国取得不动产时，须承担两项独立的申报义务。

### (1) 外国汇兑交易法申报（韩国银行/外汇银行）

在韩国境外注册的法人（非居民法人）为取得国内不动产而将资金汇入韩国或直接取得不动产时，须依据**外国汇兑交易法第18条**进行事先申报。

- 申报机关：韩国银行或外汇银行（主要往来银行）
- 申报时机：签订取得合同前或资金汇入前（以事先申报为原则）
- 未申报处罚：取得价款的一定比例（因情况而异）

### (2) 外国人土地法取得申报

外资法人在韩国取得土地（含建筑物）后，须在取得之日起**60日内**向所在地市/郡/区长进行申报。

- 申报机关：不动产所在地辖区政府
- 适用范围：外国法人及外国人或外国法人持有控股权的国内法人等
- 许可区域内的土地须在取得前取得许可，与一般地区的申报后取得程序有所不同。

> **核心要点：** 以上两项申报均为独立义务，任何一项遗漏均可能受到法律制裁。

## 2. 不动产取得5步程序

外资法人在韩国取得不动产时，须按序履行以下5个步骤。

### 第1步：事前审查与咨询

- 确认目标不动产是否属于土地交易许可区域、军事保护区、文化遗产保护区等受限区域
- 确认是否为调整对象地区（取得住宅时是否适用重税税率）
- 审查外资法适用情况（已登记为外商投资企业的可享受相关优惠）
- 聘请行政士、税务师、律师等专业人士

### 第2步：外汇申报与资金汇入

- 依外国汇兑交易法进行事先申报（韩国银行或外汇银行）
- 将投资资金汇入国内指定账户
- 准备资金来源及转移路径证明文件（须满足反洗钱标准）

### 第3步：签订买卖合同及支付定金

- 签订不动产买卖合同（以韩文为正本，建议附译文）
- 支付定金（通常为成交价的10%）
- 审查特别条款（如附外汇申报确认函等条件）

### 第4步：外国人土地法申报或许可

- 一般地区：签订买卖合同后、支付尾款前可进行申报
- 土地交易许可区域：支付尾款前须取得辖区政府的**许可**（未取得许可的交易无效）

### 第5步：支付尾款、缴纳取得税、办理登记

- 支付尾款后，在取得日起60日内申报缴纳取得税
- 向辖区登记所申请不动产所有权转移登记
- 登记完成后办理外国人土地取得申报（申报类地区须于取得后60日内完成）

## 3. 外商投资促进法主要注意事项

依外商投资促进法（外资法）登记为外商投资企业的法人，可享受多种税收优惠和政策支持。但在不动产取得方面，须注意以下事项。

### 外资法涉不动产取得的核心规定

| 事项 | 内容 |
|---|---|
| 外资法认定最低投资金额 | 1亿韩元以上（法规可能变动） |
| 可取得不动产的业种 | 原则上须与企业经营目的直接相关 |
| 纯不动产投资的限制 | 单纯以不动产租赁为目的通常不属于外资法优惠范围 |
| 税收优惠 | 被指定为外资区域的企业可享受取得税、财产税减免 |

### 注意事项

1. **业务用途与投资用途的区分：** 外资法人因经营需要取得办公室、厂房、仓库等不动产，通常无限制；但单纯以获取租金收益或资本增值为目的的取得，可能不属于外资法优惠范围。
2. **确认是否被指定为外商投资区域：** 符合一定条件的企业可申请被指定为外商投资区域，获批后可享受地价补贴及税收减免优惠。
3. **严格遵守税收减免申请期限：** 外资法规定的税收优惠有申请期限和条件要求，须提前确认。

## 4. 土地交易许可区域监管规定

政府将特定区域指定为**土地交易许可区域**，以抑制投机行为。在该区域内取得一定面积以上的土地（含建筑物）时，须事先取得辖区区长的**许可**。

### 一般许可面积标准（因区域而异）

| 用途 | 须取得许可的面积 |
|---|---|
| 住宅区 | 超过18㎡ |
| 商业区 | 超过20㎡ |
| 工业区 | 超过660㎡ |
| 绿地、农地、林地等 | 超过100~500㎡ |

> 标准面积因区域和公告内容而不同，请务必向辖区政府确认。

### 许可条件

- **真实需求原则：** 取得目的须与实际使用（居住·经营）相符，纯投机目的将被拒绝。
- **义务使用期限：** 获得许可者须在规定期限内（通常2~5年）按申报用途使用。
- **未经许可交易：** 合同本身无效，可能被处以强制履行罚款。

外资法人须遵循与国内法人相同的许可程序，同时还须并行办理外汇申报及外国人土地法申报，程序较为复杂，强烈建议通过专业人士进行事前审查。

## 5. 外资法人取得税与税务申报

### 取得税税率

外资法人取得不动产时适用以下税率：

| 物业类型 | 税率 |
|---|---|
| 住宅（调整对象地区外，一般取得） | 4%（法人标准） |
| 住宅（调整对象地区或重税对象） | 12% |
| 商业用不动产/土地 | 4% |
| 工厂/仓库等产业用 | 4% |

实务中，法人取得住宅通常无论是否属于调整对象地区均适用较高税率，12%的情况较为常见。取得前请务必与税务师确认。

### 税务申报程序

1. **取得税：** 取得之日起60日内向辖区市/郡/区政府申报缴纳
2. **增值税：** 取得经营用不动产时，作为纳税人登记，确认进项税抵扣可行性
3. **财产税：** 每年以6月1日为基准对所有者征收（7月、9月分期缴纳）
4. **法人税：** 不动产租赁收入或让渡差益须计入法人所得缴纳法人税

### 出售时税务（法人）

外资法人出售韩国境内不动产时，让渡差益须缴纳**法人税**，与法人全部所得合并征税，而非单独征收资本利得税。但出售住宅时可能适用额外税款。

## 6. 租赁业可行性与工商注册

外资法人在韩国经营不动产租赁业，须完成**国内工商注册**。

### 租赁业可行性

| 租赁类型 | 是否允许 |
|---|---|
| 商业建筑租赁（办公室/商铺） | 原则上允许 |
| 住宅租赁 | 原则上允许，但可能不在外资法优惠范围内 |
| 短期租赁（Airbnb等） | 须另行取得旅游振兴法许可 |
| 农地租赁 | 原则上受限（须查阅农地法规定） |

### 工商注册程序

1. 取得国内营业场所地址
2. 向辖区税务局申请工商注册（附法人登记证明及外国法人相关文件）
3. 发生租赁收入时，须履行增值税和法人税申报义务

> **注意：** 外资法人未完成工商注册即在韩收取租金，可能被视为逃税，并产生代扣代缴义务。出租方（外国法人）和承租方均须审查各自的税务风险。

## 7. 常见问题与预防检查清单

### 外资法人常见的问题

1. **未事先向韩国银行申报即汇入资金：** 违反外国汇兑交易法，将被处以罚款。
2. **在土地交易许可区域未取得许可即签约：** 合同无效，产生购房款返还纠纷。
3. **超过取得税申报期限：** 被征收20%未申报加算税。
4. **遗漏外国人土地取得申报：** 被处以罚款并导致登记延迟。
5. **未登记工商即收取租金：** 法人税、增值税未申报，被追缴税款。

### 取得前/中/后检查清单

**取得前**
- [ ] 查询目标不动产的监管状态（土地交易许可区域、调整对象地区等）
- [ ] 确认外国汇兑交易法事先申报要求
- [ ] 预估法人税及取得税税率
- [ ] 审查外资法优惠适用资格

**取得中**
- [ ] 取得外国汇兑申报完成确认书
- [ ] 若属土地交易许可区域，取得辖区政府许可
- [ ] 审查买卖合同特别条款

**取得后**
- [ ] 取得日起60日内申报缴纳取得税
- [ ] 提交外国人土地取得申报（60日内）
- [ ] 办理工商注册并签订租赁合同（经营租赁业时）
- [ ] 登记完成后妥善保管全部文件

## 8. 按用途的不动产取得限制摘要

| 业种/目的 | 是否可取得 | 主要注意事项 |
|---|---|---|
| 办公室/总部 | 可以 | 外汇申报、缴纳取得税 |
| 工厂/仓库 | 可以 | 工厂登记、确认土地用途 |
| 商业建筑租赁 | 可以 | 工商注册必须 |
| 住宅租赁 | 可以（外资法优惠可能不适用） | 法人取得税12%的可能性 |
| 短期租赁（旅游用途） | 须取得许可 | 须另行取得旅游振兴法许可 |
| 农地取得 | 原则上不可 | 须另行审查农地法 |
| 军事保护区土地 | 受限或不可 | 须取得国防部许可 |

## 常见问题（FAQ）

**Q1. 外资法人可以在韩国购买公寓吗？**

A: 法律上可以购买，但法人取得住宅须缴纳重税（调整对象地区12%，一般地区法人税率也偏高），且可能不在外资法优惠范围内。若以住宅租赁为目的，须另行审查相关法规，建议咨询专业人士后再做决定。

**Q2. 在土地交易许可区域未取得许可即签合同会怎样？**

A: 未经许可签订的买卖合同无效。即使支付了全部购房款，也无法取得所有权，且可能被处以强制履行罚款。签合同前请务必确认区域状态。

**Q3. 外资法人租赁商业用房时一定要办理工商注册吗？**

A: 是的。在韩国境内产生经营收入时，工商注册为强制义务。未登记即收取租金收入，可能被追缴增值税和法人税。

**Q4. 外商投资企业登记后可以自动减免取得税吗？**

A: 不能自动减免。仅有被正式指定为外商投资区域的企业，方可享受取得税和财产税减免优惠；仅凭一般外资法登记不自动触发减免，须满足具体条件并履行申请程序。

**Q5. 外国法人通过韩国子公司购买不动产，可以规避外国人监管吗？**

A: 外国人或外国法人持有一定比例以上股权的国内法人，可能被视同外国法人适用相关监管规定。构建法人架构前，请务必与法律专业人士进行审查。
