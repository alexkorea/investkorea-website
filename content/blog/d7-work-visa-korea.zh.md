## 韩国打工签证D-7详解

D-7签证是**跨国公司内部调派签证**，专为被外国总公司或关联企业派遣至韩国分支机构工作的外籍员工而设立。如果您所在的外资企业计划将您调派至韩国办公室，D-7签证是最直接的途径。

## D-7签证核心信息

| 项目 | 内容 |
|---|---|
| **签证类型** | D-7（企业内调派） |
| **适用对象** | 外资企业驻韩调派人员 |
| **初始有效期** | 1年（可续签，最长3年） |
| **家属签证** | 配偶及子女可申请F-3签证 |
| **审核时间** | 通常2～4周 |

## D-7签证申请条件

申请D-7签证必须同时满足以下条件：

- **雇主资质**：韩国境内的外国投资企业、外国公司分支机构或联络处
- **调派关系**：申请人由外国总公司调派至韩国，两者存在明确的隶属关系
- **在职年限**：申请前须在调派企业工作满**1年以上**
- **职位要求**：担任管理职、专业技术职或必要业务职
- **薪资标准**：薪资须达到韩国法定最低工资以上，通常要求与同等职位的韩国员工薪资相当

## 韩国打工签证D-7所需材料

### 申请人本人提交材料

1. **护照原件**（有效期6个月以上）及复印件
2. **签证申请表**（统一样式）
3. **近期证件照**（3.5×4.5cm，白底，6个月内拍摄）
4. **学历证明**
   - 大学毕业证书（原件或公证件）
   - 成绩单（如需）
   - 外文证书须附中韩翻译件
5. **在职证明**（原雇主出具，须含入职日期、职位、薪资信息）
6. **职业经历证明**（相关工作经历书面证明）

### 韩国雇主（调派接收方）提交材料

1. **营业执照**或外国投资企业登记证
2. **法人登记簿**（发证3个月内）
3. **调派邀请函**（须载明：调派期限、职位、担当业务、薪资）
4. **劳动合同**（中韩文各一份）
5. **纳税证明**（最近1年法人税完税证明）
6. **财务报表**（最近年度，证明企业正常运营）

### 总公司（调派方）提交材料

1. **总公司营业执照**（须经公证或认证）
2. **与韩国法人的关联关系证明**（股权结构图、登记文件）
3. **调派决定书**（由总公司管理层签署）

<div>⚠️ <strong>重要提示：</strong> 所有外文材料须附韩语翻译件，并由认证翻译机构盖章确认。材料不完整是签证被退回的最常见原因。</div>

## D-7签证申请流程

### 第一步：材料整理与预审

收集上述所有材料，由专业行政士进行预审，确认材料完整性及合规性。

### 第二步：提交签证申请

- **在韩国境外申请**：前往当地韩国大使馆或领事馆提交
- **在韩国境内申请（身份转换）**：前往出入国外国人厅（Hi Korea系统也可部分办理）

### 第三步：审核等待

审核时间通常为**2～4周**。审核期间移民局可能要求补充材料，须及时响应。

### 第四步：签证发放

审核通过后，护照将加贴D-7签证贴纸。入境韩国后须在90天内完成**外国人登记**。

## 常见被拒原因及注意事项

| 被拒原因 | 解决方法 |
|---|---|
| 在职年限不足1年 | 提前规划，确保满足年限要求 |
| 总公司与韩国法人关联证明不清 | 准备完整股权及关联关系文件 |
| 薪资证明不符合标准 | 确认调派后薪资符合法定要求 |
| 职位性质认定模糊 | 清晰描述调派职位的专业性和必要性 |
| 材料翻译不规范 | 委托专业认证翻译机构处理 |

## D-7与其他工作签证对比

| 签证类型 | 适用情况 |
|---|---|
| **D-7** | 外资企业内部调派 |
| **E-7** | 韩国企业雇用外国专业人才 |
| **D-8** | 外国人在韩投资创业 |
| **E-1～E-6** | 特定职业（教授、语言教师、演艺等） |

如您尚不确定适合哪种签证类型，建议先咨询专业行政士，根据实际情况做出判断。
