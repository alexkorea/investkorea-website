## 2026年外国人法人の韓国不動産購入手続きと注意事項

外国人法人が韓国内の不動産を取得するには、**外国為替取引法に基づく韓国銀行への申告**、**外国人土地法に基づく取得申告**、取得税の納付、登記手続きをすべて履行する必要があります。また、調整対象地域内の住宅取得時には12%の重課税率が、土地取引許可区域内の不動産取得時には別途の事前許可が必要となります。

本ガイドでは、外国人法人による国内不動産取得の5段階手続き、外国人投資促進法（外促法）の関連注意事項、賃貸業の許可の有無、税務申告方法を2026年基準で総合的に解説します。

## 1. 外国人法人の不動産取得申告義務

外国人法人が韓国内の不動産を取得する際には、2種類の独立した申告義務があります。

### (1) 外国為替取引法に基づく申告（韓国銀行・外国為替銀行）

韓国国外に住所を有する法人（非居住者法人）が国内不動産を取得するために資金を国内に持ち込んだり不動産を取得する場合、**外国為替取引法第18条**に基づく事前申告が必要です。

- 申告機関：韓国銀行または外国為替銀行（主要取引銀行）
- 申告時期：取得契約締結前または資金持ち込み前（事前申告が原則）
- 未申告時の制裁：取得価額の一定割合（事案によって異なる）

### (2) 外国人土地法に基づく取得申告

外国人法人が国内の土地（建物を含む）を取得した場合、取得日から**60日以内**に市長・郡守・区庁長への申告が必要です。

- 申告機関：不動産所在地の管轄市・郡・区役所
- 対象：外国法人および外国人・外国法人が筆頭株主である国内法人等を含む
- 許可区域内の土地は取得前の許可が必要であり、申告後取得が可能な一般地域とは区別されます。

> **重要ポイント：** 2つの申告はいずれも独立した義務です。いずれか一方を欠いても法的制裁を受ける可能性があります。

## 2. 不動産取得5段階手続き

外国人法人が国内不動産を取得する際には、以下の5段階を順番に履行する必要があります。

### ステップ1：事前検討と専門家への相談

- 対象不動産が土地取引許可区域・軍事保護区域・文化財保護区域等の規制地域に該当するか確認
- 調整対象地域か否か確認（住宅取得時の重課税率適用有無）
- 外促法の適用有無（外国人投資企業として登録している場合、各種優遇措置あり）
- 行政士・税理士・弁護士等の専門家を選任

### ステップ2：外国為替申告と資金持ち込み

- 外国為替取引法に基づく事前申告（韓国銀行または外国為替銀行）
- 投資資金を国内指定口座に送金
- 資金出所・経路の証明書類を準備（マネーロンダリング防止基準を満たす必要あり）

### ステップ3：売買契約の締結と手付金の支払い

- 不動産売買契約書の作成（韓国語正本＋翻訳版を推奨）
- 手付金（通常10%）の支払い
- 特約条項（外国為替申告確認書の添付等）の確認

### ステップ4：外国人土地法に基づく申告または許可

- 一般地域：契約締結後、残金支払い前に申告可能
- 土地取引許可区域：残金支払い前に管轄区役所の**許可**取得が必須（許可なしの取引は無効）

### ステップ5：残金支払い・取得税納付・登記

- 残金支払い後、取得税を取得日から60日以内に申告・納付
- 不動産所有権移転登記の申請（管轄登記所）
- 登記完了後、外国人土地取得申告（申告後取得の地域では取得後60日以内）

## 3. 外国人投資促進法の主要注意事項

外促法に基づいて外国人投資企業として登録した法人は、さまざまな税制優遇と支援を受けることができます。ただし、不動産取得に関しては以下の点に注意が必要です。

### 外促法上の不動産取得関連規定

| 項目 | 内容 |
|---|---|
| 外国人投資企業認定の最低投資額 | 1億ウォン以上（法令変更の可能性あり） |
| 不動産取得が認められる業種 | 原則として事業目的と直接関連する用途 |
| 不動産専用投資の制限 | 単純不動産賃貸業目的のみでは外促法優遇措置の対象外となる可能性 |
| 税制優遇 | 外国人投資区域に指定された法人は取得税・財産税の減免が可能 |

### 注意事項

1. **業務用と投資用の区別：** 外国人法人が事務所・工場・倉庫等の事業目的で不動産を取得する場合は一般的に制限がありませんが、単純な賃貸収益または値上がり益を目的とする取得は外促法優遇の対象外となる可能性があります。
2. **外国人投資地域の指定確認：** 一定の要件を満たす場合、外国人投資地域の指定申請が可能であり、指定を受けると地価補助・税制減免の優遇があります。
3. **税制減免申請期限の厳守：** 外促法に基づく税制優遇は申請期限と要件が定められているため、事前に確認する必要があります。

## 4. 土地取引許可区域の規制

政府は投機抑制のため、特定地域を**土地取引許可区域**に指定します。この区域内で一定面積以上の土地（建物を含む）を取得する場合は、管轄区庁長の**事前許可**が必要です。

### 許可が必要な面積の一般基準（地域により異なる）

| 用途 | 許可が必要な面積 |
|---|---|
| 住宅地域 | 18㎡超 |
| 商業地域 | 20㎡超 |
| 工業地域 | 660㎡超 |
| 緑地・農地・林野等 | 100～500㎡超 |

> 基準面積は地域と告示内容によって異なるため、管轄区役所で必ず確認してください。

### 許可要件

- **実需要原則：** 取得目的が実際の利用（居住・事業）に合致していることが必要であり、単純な投機目的は不許可となります。
- **義務的利用期間：** 許可を受けた場合、一定期間（通常2～5年）の義務的利用条件が付されます。
- **許可なしの取引：** 契約自体が無効となり、履行強制金が課せられることがあります。

外国人法人は内国法人と同一の許可手続きを踏みますが、外国為替申告および外国人土地法上の申告を並行して行う必要があるため、手続きが複雑になります。専門家を通じた事前検討を強くお勧めします。

## 5. 外国人法人の取得税と税務申告

### 取得税率

外国人法人が不動産を取得する場合、以下の税率が適用されます。

| 物件種別 | 税率 |
|---|---|
| 住宅（調整対象地域外、一般取得） | 4%（法人基準） |
| 住宅（調整対象地域または重課対象） | 12% |
| 商業用不動産・土地 | 4% |
| 工場・倉庫等（産業用） | 4% |

実務上、法人が住宅を取得する場合は調整対象地域か否かにかかわらず高い税率が適用されることが多く、12%が課される事例が多くなっています。取得前に必ず税理士に確認してください。

### 税務申告手続き

1. **取得税：** 取得日から60日以内に管轄市・郡・区役所で申告・納付
2. **付加価値税：** 事業用不動産取得の場合は課税事業者として登録し、仕入税額控除の可否を確認
3. **財産税：** 毎年6月1日基準の所有者に課税（7月・9月に分割納付）
4. **法人税：** 不動産賃貸収入または譲渡差益は法人税の課税対象

### 譲渡時の税務（法人）

外国人法人が国内不動産を譲渡する場合、譲渡差益は**法人税**の課税対象となります。個人の譲渡所得税とは異なり、法人税は法人全体の所得に合算して課税されます。ただし、住宅の譲渡時は追加課税が適用される場合があります。

## 6. 賃貸業の許可と事業者登録

外国人法人が国内で不動産賃貸業を営む場合、**国内の事業者登録**が必須です。

### 賃貸業の許可の有無

| 賃貸の種類 | 許可の有無 |
|---|---|
| 商業用建物の賃貸（事務所・店舗） | 原則として許可 |
| 住居用住宅の賃貸 | 原則として許可、ただし外促法優遇の対象外となる可能性 |
| 短期賃貸（Airbnb等） | 観光振興法による別途の許可が必要 |
| 農地の賃貸 | 原則として制限（農地法の規定を確認） |

### 事業者登録手続き

1. 国内事業所の住所を確保
2. 管轄税務署に事業者登録を申請（法人登記簿謄本、外国法人関連書類を含む）
3. 賃貸収入が発生した場合、付加価値税および法人税の申告義務が生じる

> **注意：** 外国人法人が国内で事業者登録なしに賃貸収益を受け取る場合、租税回避とみなされることがあり、源泉徴収義務が発生します。賃貸人（外国法人）と賃借人の双方が税務リスクを確認する必要があります。

## 7. よくある問題と予防チェックリスト

### 外国人法人が頻繁に直面する問題

1. **韓国銀行への事前申告なしに資金を持ち込む：** 外国為替取引法違反で過料が課せられます。
2. **土地取引許可区域で許可なしに契約を進める：** 契約が無効となり、売買代金の返還をめぐる紛争が発生します。
3. **取得税申告期限を超過：** 20%の無申告加算税が課せられます。
4. **外国人土地取得申告の漏れ：** 過料が課せられ、登記が遅延します。
5. **事業者登録なしに賃貸収入を受け取る：** 法人税・付加価値税の無申告として追徴されます。

### 取得前・中・後のチェックリスト

**取得前**
- [ ] 対象不動産の規制状況を確認（土地取引許可区域、調整対象地域等）
- [ ] 外国為替取引法上の事前申告手続きを確認
- [ ] 法人税・取得税の税率を事前に検討
- [ ] 外促法優遇の適用資格を検討

**取得中**
- [ ] 外国為替申告完了確認書の受領
- [ ] 土地取引許可区域の場合、区役所の許可を取得
- [ ] 売買契約書の特約条項を確認

**取得後**
- [ ] 取得日から60日以内に取得税を申告・納付
- [ ] 外国人土地取得申告（60日以内）
- [ ] 事業者登録および賃貸契約の締結（賃貸業を行う場合）
- [ ] 登記完了後、関連書類を保管

## 8. 目的別不動産取得制限の概要

| 業種・目的 | 取得可否 | 主な注意事項 |
|---|---|---|
| 事務所・本社用途 | 可 | 外国為替申告・取得税納付 |
| 工場・倉庫 | 可 | 工場登録・土地用途確認 |
| 商業用建物の賃貸 | 可 | 事業者登録が必須 |
| 住居用住宅の賃貸 | 可（外促法優遇対象外の可能性） | 法人取得税12%の可能性 |
| 短期賃貸（観光用） | 許可が必要 | 観光振興法上の別途許可が必要 |
| 農地の取得 | 原則不可 | 農地法の別途確認が必要 |
| 軍事保護区域の土地 | 制限または不可 | 国防部の許可が必要 |

## よくある質問（FAQ）

**Q1. 外国人法人も韓国でマンションを購入できますか？**

A: 法的には取得可能ですが、法人による住宅取得は重課税率（調整対象地域12%、一般地域でも法人は高い税率）が適用され、外促法優遇の対象外となる可能性があります。住居用賃貸を目的とする場合は別途の規制を確認する必要があり、専門家への相談を推奨します。

**Q2. 土地取引許可区域の不動産を許可なしで契約した場合はどうなりますか？**

A: 許可なしに締結した売買契約は効力がありません。残金を支払っても所有権を取得できず、履行強制金が課せられることがあります。必ず契約前に区域の状況を確認してください。

**Q3. 外国人法人が商業用物件を賃貸する場合、事業者登録は必須ですか？**

A: はい。国内で事業所得が発生する場合、事業者登録は義務です。登録なしに賃貸収入を受け取ると、付加価値税および法人税の無申告として追徴されることがあります。

**Q4. 外国人投資企業として登録すると取得税が自動的に減免されますか？**

A: 自動的には減免されません。外国人投資地域に指定された法人のみ、取得税・財産税の減免を受けられる可能性がありますが、一般的な外促法登録だけでは適用されず、具体的な要件と申請手続きがあります。

**Q5. 外国法人が国内子会社を通じて不動産を取得すれば、外国人規制を回避できますか？**

A: 国内法人であっても、外国人や外国法人が一定割合以上の持分を保有している場合、外国人法人に準じた規制が適用される可能性があります。法人構造の設計前に必ず法律の専門家に相談してください。
