本文面向在韩国经营分公司或办事处的外国企业，计划将其结束并以韩国法人（子公司）形式继续经营的情形。只是出资方式不同，外国人投资的要件以及申报、登记义务照样适用。

## 要点摘要

- 出资标的物包括：对外支付手段、资本货物、股份孳息、产业财产权等技术、分公司或办事处关闭及韩国法人解散时的清算剩余财产、借款偿还额、股份、韩国境内不动产等
- 关闭分公司或办事处并转为其他韩国法人时，因清算分配给外国人的剩余财产属于出资标的物
- 以取得股份方式进行的外国人投资，须投资金额1亿韩元以上，并持有10%以上有表决权的股份（或派遣、选任高管）
- 取得设立中法人的股份也属于外国人投资
- 外国人投资须事先申报并领取申报证明书（受理业务委托给大韩贸易投资振兴公社和外汇银行）
- 出资标的物缴纳完毕之日起60日内办理外国人投资企业登记
- 分公司清算本身的登记、税务、外汇程序以及员工的滞留资格，须另行确认

## 1. 为什么分公司的剩余财产可以成为出资？

《外国人投资促进法》把外国投资者为持有股份等而出资的财产称为"出资标的物"，并规定了其种类。

| 出资标的物种类 | 内容 |
|---|---|
| 对外支付手段 | 《外汇交易法》规定的对外支付手段或因兑换而产生的国内支付手段 |
| 资本货物 | 作为产业设施的机械、器材等 |
| 孳息 | 依本法取得的股份等所产生的孳息 |
| 技术 | 产业财产权、知识产权以及与之相当的技术及其使用权 |
| 清算剩余财产 | 关闭分公司、办事处并转为其他韩国法人，或外国人持股的韩国法人解散时，因清算分配给外国人的剩余财产 |
| 其他 | 借款等海外借入款的偿还额、总统令规定的股份、韩国境内不动产等 |

在结束分公司、把业务转到新的韩国法人时，法律允许将分公司清算后返还给外国人（总公司）的剩余财产出资到新法人。

## 2. 要被认定为外国人投资，需要满足哪些要件？

即使以剩余财产出资，以取得股份方式进行的外国人投资要件也相同。

- 投资金额1亿韩元以上
- 外国人持有韩国法人（包括设立中的法人）已发行有表决权股份总数或出资总额的10%以上，或在持有股份等的同时向该法人派遣、选任高管

两名以上外国人共同投资时，投资金额按每人金额计算。剩余财产最终确定为多少取决于清算结果，因此是否满足1亿韩元要件需根据个案确认。

## 3. 申报在什么时候、向哪里提出？

外国人进行外国人投资时须事先向产业通商部长官申报，受理申报后会立即发放申报证明书。申报、变更申报的受理和申报证明书的发放委托给大韩贸易投资振兴公社社长和外汇银行行长，实务中向这些机构提交。

申报内容中外国人投资比例与投资金额、外国投资者或外国人投资企业的商号与地址、拟经营的业务等发生变化时，可以进行变更申报。清算后实际出资金额可能与最初申报不同，应提前考虑这一点。

## 4. 缴纳后如何办理外国人投资企业登记？

外国投资者或外国人投资企业在出资标的物缴纳完毕时，须办理外国人投资企业登记，期限为该事由发生之日起60日内。登记申请书向大韩贸易投资振兴公社社长或外汇银行行长（受托机构）提交，并附法人登记事项证明书、股东名册、营业执照复印件等。符合登记要件的，会发放外国人投资企业登记证明书。

| 阶段 | 内容 |
|---|---|
| ① 事先申报 | 出资前申报外国人投资，领取申报证明书 |
| ② 清算与出资 | 将分公司、办事处清算分配的剩余财产出资到新法人 |
| ③ 登记 | 缴纳完毕之日起60日内办理外国人投资企业登记，领取登记证明书 |
| ④ 变更 | 登记事项变更时，自事由发生之日起60日内办理变更登记 |

以剩余财产出资时登记申请需附哪些证明材料，可能因出资形态而异，最好事先向受托机构确认。

## 5. 分公司清算和员工的滞留资格怎么办？

分公司、办事处的关闭和清算本身涉及登记、税务、外汇申报等其他法令的程序，与本文的外国人投资程序分别进行。在分公司工作的外国员工，其工作单位和所属法人会发生变化，是否需要变更滞留资格或办理工作单位相关申报，需根据个案确认。

## 6. 常见问题有哪些？

- 认为剩余财产出资不是海外汇款，就不需要外国人投资申报
- 清算后剩余财产不足1亿韩元，却没有准备其他出资方式
- 出资完毕后未在60日内办理外国人投资企业登记
- 清算金额与最初申报不同，却没有考虑变更申报
- 把分公司员工滞留资格的处理推迟到法人设立之后

## 常见问题

### 分公司的财产可以作为新法人的出资吗？

关闭分公司或办事处并转为其他韩国法人时，因清算分配给外国人的剩余财产属于《外国人投资促进法》规定的出资标的物。

### 以剩余财产出资也需要外国人投资申报吗？

进行外国人投资须事先申报，不论出资标的物种类如何，该义务都相同。申报后会立即发放申报证明书。

### 不足1亿韩元怎么办？

以取得股份方式进行的外国人投资要求投资金额1亿韩元以上，剩余财产不足时，是否合并使用其他出资标的物等方法需根据个案确认。

### 登记期限是什么时候？

须在出资标的物缴纳完毕之日起60日内，向大韩贸易投资振兴公社或外汇银行办理外国人投资企业登记。

### 韩国法人解散时的剩余财产也适用吗？

适用。外国人持股的韩国法人解散时，因该法人清算分配给外国人的剩余财产也属于出资标的物。
