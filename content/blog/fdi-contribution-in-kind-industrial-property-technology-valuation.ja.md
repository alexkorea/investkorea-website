できます。外国人投資促進法は、外国投資家が株式等を保有するために出資するものを「出資目的物」と呼び、外貨（対外支払手段）のほかに資本財、産業財産権と技術、一定の株式、韓国内の不動産、韓国内の支店・事務所を閉鎖して法人に転換する際の残余財産などを定めています。現物で出資する場合は、価格を誰がどのように確認するかが要点で、この法律は資本財と産業財産権について商法の手続に代わる特例を設けています。

この記事は、海外本社の設備や特許を韓国法人に出資しようとする外国投資家と、合弁パートナーである韓国企業の実務担当者のための案内です。

## 要点

- 出資目的物：外貨などの対外支払手段、資本財、株式等から生じた果実、産業財産権・知的財産権・技術、支店・事務所の閉鎖や法人解散時の残余財産、借款などの償還額、一定の株式、韓国内の不動産、株式・不動産の処分代金
- 知的財産権は産業活動に利用される著作権と半導体の回路配置設計権、株式は外国の証券市場に上場された外国法人の株式など
- 資本財の現物出資は、関税庁長が確認した現物出資完了確認書を商法上の検査役の調査報告書とみなす
- 技術評価機関が産業財産権等を評価すれば、商法上の公認された鑑定人が鑑定したものとみなす
- 出資のために導入する資本財は輸入申告の受理前までに検討・確認を申請でき、受ければ輸入承認を受けたものとみなす
- 出資目的物の払込みを終えたら外国人投資企業の登録、払込みを仮装した登録は抹消の対象

## 1. 現金以外に何で出資できますか？

外国人投資促進法が定める出資目的物は次のとおりです。

| 区分 | 内容 |
|---|---|
| 対外支払手段 | 外国為替取引法による対外支払手段、またはその交換で生じる国内支払手段 |
| 資本財 | 産業施設としての機械・機材・施設品・器具・部品・付属品など |
| 果実 | この法律により取得した株式等から生じた果実 |
| 産業財産権等 | 産業財産権、大統領令で定める知的財産権、これに準ずる技術とその使用に関する権利 |
| 残余財産 | 韓国内の支店・事務所を閉鎖して国内法人に転換し、または国内法人が解散する際、清算により分配される残余財産 |
| 償還額 | 長期借款やその他の海外借入金の償還額 |
| 株式 | 大統領令で定める株式 |
| 不動産 | 韓国内にある不動産 |
| 処分代金 | 外国人が保有する韓国の法人・企業の株式等と不動産を処分した代金 |

資本財には、船舶・車両・航空機などの産業施設のほか、農業・林業・水産業の発展に必要な家畜・種子・樹木・魚介類、最初の試運転に必要と認められる原料・予備品、導入に伴う運賃・保険料、施設や助言の技術・役務が含まれます。

## 2. どの知的財産権と株式が認められますか？

施行令は、出資できる知的財産権を、著作権法による著作権のうち産業活動に利用される権利と、半導体集積回路の回路配置設計権と定めています。特許権などの産業財産権、これに準ずる技術、その使用に関する権利は、法律で直接出資目的物とされています。

出資できる株式は、外国の証券市場に上場された外国法人の株式と、この法律または外国為替取引法により外国人が保有している株式です。非上場の外国法人株式はこの一覧に入っていないため、個別の事案に応じて確認が必要です。

## 3. 機械・設備を現物出資するとき、価格は誰が確認しますか？

商法上、現物出資は原則として検査役の調査を経ます。外国人投資促進法は、外国投資家が資本財を現物出資する場合、関税庁長が現物出資の履行とその目的物の種類・数量・価格などを確認した現物出資完了確認書を、商法上の検査役の調査報告書とみなします。会社設立後に資本財を現物出資する場合も同じです。

現物出資完了確認を受けるには、所定の様式（別紙第25号様式）の申請書2部を関税庁長に提出します。関税庁長は行政情報の共同利用で輸入申告済証を確認し、申請者が確認に同意しない場合はその書類を添付させます。確認を終えると、関税庁長は韓国銀行総裁に通報します。

## 4. 設備を導入する前にすることは？導入物品の検討・確認

外国投資家が出資の目的物として導入する資本財等は、主務部長官の検討・確認を受けることができ、検討・確認を受けた資本財等は対外貿易法による輸入承認を受けたものとみなされます。

検討・確認を受けるには、資本財の数量・規格・価格・製作者などを記載した導入物品明細書を作成し、輸入申告の受理前までに申請しなければなりません。この業務は外国為替銀行の長と大韓貿易投資振興公社の長に委託されており、申請書（別紙第24号様式）3部に物品売渡確約書など価格を証明する書類を添えて提出します。

| 事由 | 申請期限 |
|---|---|
| 原則 | 輸入申告の受理前まで |
| 関税法により関税を納付する場合 | 納付告知を受けた日から5日以内 |
| 物品が保税区域から搬出されていない場合 | 輸入申告の受理日から15日以内 |

## 5. 特許・技術を出資するとき、価格評価はどうしますか？

大統領令で定める技術評価機関が産業財産権等の価格を評価した場合、その評価内容は商法により公認された鑑定人が鑑定したものとみなされます。ここでいう技術評価機関は、ベンチャー企業関連法令の施行令が定める評価機関です。どの機関が該当するか、評価にかかる期間は、個別の事案に応じて確認が必要です。

株式・債券・韓国内の不動産を出資する場合は、外国人投資企業の登録時に商法による検査役の調査報告書または鑑定人の鑑定結果の写しを提出しなければなりません。

## 6. 出資後の外国人投資企業の登録はどうなりますか？

外国投資家または外国人投資企業は、出資目的物の払込みを終えたら外国人投資企業の登録をしなければなりません。登録申請の際は、出資方法に応じて次の書類の写しを添付します。

- 現物出資以外の場合：送金人が確認できる外貨買入証明書または外貨預金証明書
- 資本財を出資する場合：現物出資完了確認書
- 株式・債券・韓国内の不動産を出資する場合：検査役の調査報告書または鑑定人の鑑定結果
- 共通：法人登記事項証明書、株主名簿、事業者登録証または固有番号証

出資目的物の払込みを仮装して外国人投資企業の登録をした場合、登録は抹消されます。価格を水増ししたり、実際には引き渡していない現物を出資したように装ったりすると、登録そのものが崩れるおそれがあります。

## 7. よくあるトラブル

- 設備を先に通関し、導入物品の検討・確認の期限を過ぎてしまった
- 現物出資完了確認を考えず、商法上の検査役の手続だけで日程を組んだ
- 非上場の外国法人株式を出資目的物に使えると考えた
- 技術出資で、評価機関が施行令の定める機関かどうかを確認しなかった
- 韓国の合弁パートナーが出資目的物の再評価の特例（毎月1日を再評価日とする）を知らず、帳簿価額で交渉した

## よくある質問

### 海外本社の中古機械も出資できますか？

産業施設としての機械・機材などの資本財は出資目的物です。関税庁長が種類・数量・価格などを確認した現物出資完了確認書が、商法上の検査役の調査報告書に代わります。

### 特許を出資する場合、鑑定は誰がしますか？

施行令の定める技術評価機関が産業財産権等の価格を評価すれば、商法上の公認された鑑定人が鑑定したものとみなされます。

### ソフトウェアの著作権も出資できますか？

著作権法による著作権のうち産業活動に利用される権利は、出資目的物となる知的財産権に含まれます。具体的に該当するかは個別の事案に応じて確認が必要です。

### 韓国の支店を法人に変えるとき、支店の財産を出資できますか？

外国人が韓国内の支店や事務所を閉鎖して別の国内法人に転換する場合、清算によりその外国人に分配される残余財産は出資目的物です。

### 設備導入の検討・確認はいつまでに申請しますか？

原則として輸入申告の受理前までです。関税を納付する場合は納付告知を受けた日から5日、保税区域から搬出されていない場合は輸入申告の受理日から15日以内に申請できます。
