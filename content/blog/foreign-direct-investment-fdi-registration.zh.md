# 韩国外国直接投资(FDI)申报程序完整指南

凡外国人或外国法人计划在韩国设立法人或向韩国企业出资，均须依据《外国人投资促进法》完成**外国直接投资(FDI)申报**。若未办理申报手续，将无法享受法律保护、税收优惠，也不符合D-8投资签证的申请条件。本指南将逐步说明申报义务、流程、投后登记及签证办理全过程。

## 1. 什么是外国直接投资？

根据《外国人投资促进法》第2条，**外国直接投资(FDI)**是指外国个人或法人向韩国法人出资，取得该法人**10%及以上股权**，或虽不足10%但实质参与经营管理的投资行为。

### 法律依据

- **法律依据**：外国人投资促进法第2条
- **投资主体**：外国个人、外国法人、无韩国国籍的海外韩裔
- **投资对象**：取得韩国法人股份/股权、提供5年以上长期贷款、设立营业所

### FDI类型

| 类型 | 说明 |
|---|---|
| **新设投资** | 设立新法人并取得股权 |
| **增资** | 参与现有法人有偿增资 |
| **并购(M&A)** | 收购现有股份或股权 |

## 2. FDI申报义务

### 投资前申报原则

外国直接投资必须在**投资实施前**完成申报，即在汇款或取得股权之前。该原则无任何例外。

> **核心要点**：请在汇款或取得股权**之前**完成FDI申报并获取确认书。

### 申报对象

- 取得韩国法人股份/股权（新设法人或现有法人）
- 向韩国企业提供5年以上长期贷款
- 在韩设立营业所或联络处

### 申报豁免情形

以下情形无需办理FDI申报（适用其他申报程序）：

- 持有上市公司股票低于10%且不参与经营管理的证券投资
- 单纯购置不动产（适用《外汇交易法》另行申报）

## 3. 申报流程

### 申报机构

FDI申报可通过以下两种途径之一办理：

**① 指定外汇银行（지정거래외국환은행）**
- 依据《外汇交易法》获授权的银行（KEB韩亚银行、新韩银行、友利银行、国民银行等）
- 可到网点办理或通过网银申报

**② KOTRA（大韩贸易投资振兴公社）**
- 在线申报：[www.investkorea.org](https://www.investkorea.org)
- 全国各地KOTRA地区总部现场办理

### 所需材料

| 材料 | 备注 |
|---|---|
| 外国人投资申报书 | 按规定格式填写 |
| 投资人身份证明 | 护照复印件（个人）/ 法人登记证明（法人） |
| 投资金额证明材料 | 余额证明书、资金来源确认书等 |
| 法人登记簿誊本或设立计划书 | 现有法人投资：提交登记证明；新设法人：提交设立计划 |
| 事业计划书 | 说明投资目的及主营业务内容 |

### 申报→登记流程

```
提交外国人投资申报书
        ↓
申报受理（1~3个工作日）
        ↓
领取外国人投资申报证明书
        ↓
汇入投资款（境外汇款或实物出资）
        ↓
完成法人设立或增资
```

### 变更申报

投资金额增加、经营范围变更、投资人变更等情形发生时，须另行办理**变更申报**。

## 4. 投资后登记

FDI申报获受理并完成投资款缴纳后，须依次完成以下后续登记：

### ① 法人设立登记（법인설립등기）

- 受理机关：所在地管辖法院登记所
- 所需材料：公司章程、股东名册、董事会会议记录、外国人投资申报证明书等
- 办理时间：约5~7个工作日

### ② 营业执照（事业者注册）

- 受理机关：所在地税务署或Hometax（国税厅网站）
- 须在法人设立登记完成后申请
- 办理时间：约2~3个工作日

### ③ 外国人投资企业登记（외국인투자기업 등록）

- 受理机关：法人所在地市/道知事或KOTRA
- 领取外国人投资企业确认证
- 享受各类政府扶持政策及税收优惠的必要前提

### 整体时间节点（参考）

| 阶段 | 所需时间 |
|---|---|
| FDI申报受理 | 1~3个工作日 |
| 投资款汇入及确认 | 2~5个工作日 |
| 法人设立登记 | 5~7个工作日 |
| 营业执照申请 | 2~3个工作日 |
| **预计总用时** | **约2~4周** |

## 5. D-8签证关联

### D-8签证简介

D-8（企业投资）签证面向已完成FDI申报的外国投资人，用于在韩国外国人投资企业从事**经营管理**或生产技术工作。

### D-8签证申请条件

- 已完成外国直接投资申报
- 每位投资人投资金额达**1亿韩元以上**
- 已完成外国人投资企业登记
- 企业实际经营（空壳公司不符合资格）

### D-8签证申请流程

1. 完成FDI申报及法人设立
2. 取得外国人投资企业登记证
3. 向出入境管理局提交D-8签证申请
4. 签证签发（通常需3~5个工作日）

> D-8签证通常以2~5年为单位签发，入境后须办理外国人登记并可申请续签。

## 6. 行业限制

### 完全开放行业

制造业、IT/软件、批零售、餐饮住宿、物流等绝大多数行业无需特别许可，可直接进行FDI。

### 限制行业（需特别批准）

| 行业 | 限制内容 |
|---|---|
| **国防军工** | 原则上禁止外国人投资或严格限制 |
| **广播与电信** | 依《广播法》《电信事业法》设有股权上限 |
| **金融与保险** | 须事先获得金融当局批准 |
| **教育（学校法人）** | 外国人设立受限 |
| **电力与天然气** | 以公益性为由限制进入 |

### 限制行业查询方式

- **KOTRA外国人投资信息系统**：[www.investkorea.org](https://www.investkorea.org)
- **外国人投资促进法附表一、附表二**

## 7. 常见问题

**Q. 未申报直接投资会有什么后果？**
> 将依《外国人投资促进法》处以最高1亿韩元罚款，且无法享受外国人投资企业的任何优惠政策，也不符合D-8签证的申请条件。部分情况下可事后补报，但会产生不利影响，建议务必提前申报。

**Q. 投资金额有最低要求吗？**
> 依据《外国人投资促进法施行令》，最低投资额为1亿韩元。D-8签证申请同样要求每位投资人投资额不低于1亿韩元。

**Q. 是否需要同时办理FDI申报和外汇申报？**
> 通过指定外汇银行申报的，FDI申报与外汇交易申报可同步处理。通过KOTRA申报的，则须另行通过外汇银行完成汇款及确认手续。

**Q. 法人设立前可以先办理FDI申报吗？**
> 可以。新设投资情形下，可在法人成立前附上设立计划书先行提交FDI申报，申报受理后再推进法人设立手续。

**Q. 多名外国人共同出资时，每人是否都要单独申报？**
> 是的，每位投资人须按各自出资额分别办理FDI申报。

**Q. 想投资限制行业，应如何获得批准？**
> 须先取得主管部门（防卫事业厅、广播通信委员会、金融委员会等）的事前批准，方可办理FDI申报。
