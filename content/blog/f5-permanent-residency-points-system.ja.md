## 韓国永住権のポイント制とは

韓国の永住権（F-5）取得には複数のルートがありますが、多くの外国人専門職に適用されるのが**ポイント制（점수제）**を活用したルートです。まずF-2-7（ポイント制居留ビザ）を取得し、継続居住後にF-5永住権へ転換します。

<img src="https://images.pexels.com/photos/1181467/pexels-photo-1181467.jpeg?auto=compress&cs=tinysrgb&w=800" alt="韓国ビジネス環境" />

## ポイント制の概要

| 項目 | 内容 |
|---|---|
| **対象ビザ** | F-2-7（ポイント制居留） |
| **F-2-7申請要件** | 合計80点以上 |
| **F-5転換要件** | F-2-7取得後3年以上継続居住 |
| **満点** | 120点（基準点80点以上で申請可） |

年収は韓国の**전년도 1인당 GNI（一人当たりGNI）**との比較で評価されます。

| 年収基準（対GNI比） | 取得ポイント |
|---|---|

| GNIの2倍以上〜3倍未満 | 16点 |
| GNIの1.5倍以上〜2倍未満 | 14点 |
| GNIの1倍以上〜1.5倍未満 | 12点 |
| GNI未満 | 0点 |

※2026年基準GNI：約4,300万ウォン（年額）

## F-2-7からF-5への転換条件

F-2-7ビザを取得後、以下の条件を満たすことでF-5永住権への転換申請が可能になります。

1. **継続居住3年以上**（F-2-7取得日から）
2. **居住要件の維持**（単純出国は問題なし、長期不在に注意）
3. **犯罪歴なし**（交通違反の罰金履歴も影響する場合あり）
4. **健康保険料の完納**
5. **税金の完納**（所得税・地方税）

```
     ↓

```

## よくある質問

**Q. 転職・退職するとポイントや在留資格はどうなりますか？**
F-2-7取得後は就労先が変わっても在留資格は維持されます。ただし更新時には現在の雇用・所得状況が再審査されます。

**Q. 日本の大学を卒業しました。学歴証明書はどう準備しますか？**
卒業証明書は日本語原本に加え、韓国語の認証翻訳が必要です。アポスティーユ（外務省の認証）を取得しておくとスムーズです。

**Q. TOPIK試験の有効期限はありますか？**
TOPIKの合格証明書には有効期限がありません（永久有効）。ただし、申請時に最新の成績であることが望ましいとされる場合があります。
