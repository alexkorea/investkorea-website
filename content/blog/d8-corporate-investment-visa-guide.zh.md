# 韩国D-8企业投资签证完全指南

外国人若计划在韩国设立法人，或向现有韩国法人投资并担任经营职务，则需申请 **D-8企业投资签证**。与一般工作签证不同，D-8签证以投资实绩和经营参与为前提，是连接长期居留、携家属同行及申请永久居留的重要签证类别。本指南将全面介绍D-8签证的各项要点。

---

## 1. D-8签证概述

D-8（企业投资）签证依据《外国人投资促进法》颁发，面向在韩投资法人并参与经营管理的外国人。持证人可合法在韩从事所投资企业的经营与管理活动。

### 主要特征

- **申请目的**：外国人投资企业的经营与管理
- **居留期限**：单次最长5年，可续签
- **携带家属**：配偶及未成年子女可申请F-3（随行）签证入韩
- **工作许可**：仅限在所投资企业从事经营管理职务

### D-8细分类别

| 类别 | 适用对象 | 核心条件 |
|------|----------|----------|
| **D-8-1** | 外国人投资企业代表/高管 | 投资额不低于1亿韩元 |
| **D-8-2** | 技术型创业企业代表/高管 | 以技术为核心的初创企业，需满足特定技术条件 |
| **D-8-3** | 经专业机构推荐创业者 | 需获得公共机构或风险投资机构等指定机构的推荐 |

---

## 2. 申请资格条件

### 所有类别通用条件

1. **外国人投资登记**：须完成向韩国进出口银行的外国人投资申报及登记
2. **设立法人或取得股权**：在韩设立法人，或取得现有韩国法人的股权
3. **担任经营职务**：须担任代表理事、理事、监事等登记高管职务，或具备同等经营者地位
4. **劳动合同**：持有与投资企业签订的劳动合同或高管任命相关证明材料

### D-8-1附加条件

- 已实缴投资额不低于1亿韩元（约合人民币50万元）
- 所投资企业须符合《外国人投资促进法》第2条规定的"外国人投资企业"认定标准

### D-8-2附加条件

- 具备理工科学士及以上学历，或同等技术经验
- 提交以技术为核心的商业计划书，并获相关机构审核确认

### D-8-3附加条件

- 持有KOTRA、韩国创业振兴院、认定风投机构等指定机构出具的推荐函
- 通过创业可行性审查

## 3. 最低投资额

### D-8-1标准

| 投资方式 | 最低投资额 |
|----------|-----------|
| 新设法人 | **1亿韩元以上**（约合人民币50万元） |
| 取得现有法人股权 | **1亿韩元以上**（以取得股权价值计算） |

> **注意**：投资金额须为实际已缴纳的资金，借款或贷款资金不被认定为投资额。

### D-8-2及D-8-3标准

技术型创业及专业机构推荐创业类别的最低投资额要求可能有所宽松，审核时将综合考量技术能力、商业计划质量及推荐机构评估意见。具体适用标准请在申请前向出入境管理事务所或专业人士确认。

## 4. 申请所需材料

### 基础通用材料

1. 综合签证申请表
2. 护照原件及复印件
3. 近期照片1张（6个月内拍摄，3.5×4.5厘米）
4. 申请费

### 法人及投资相关材料

| 材料 | 说明 |
|------|------|
| 外国人投资企业登记证 | 由韩国进出口银行颁发 |
| 法人登记簿誊本 | 3个月内开具 |
| 事业者登记证（营业执照） | 由税务署颁发 |
| 外国人投资申报受理确认 | 进出口银行受理确认文件 |
| 股东名册 | 须加盖法人印章 |

### 个人及财务相关材料

| 材料 | 说明 |
|------|------|
| 劳动合同或高管任命文件 | 已登记高管可以法人登记簿誊本替代 |
| 银行存款余额证明 | 证明投资款已缴纳 |
| 商业计划书 | 包含经营发展计划 |
| 最近一期财务报表 | 取得现有法人股权时需提供 |
| 纳税证明 | 如适用 |

> 所需材料因签证类别、申请地点（境内或境外）及个人情况不同而有所差异，申请前建议咨询专业人士。

## 5. 申请流程

### 境内申请（变更签证身份 / 续签）

```
① 准备材料 → ② 前往出入境·外国人厅提交申请
→ ③ 审核（通常需2~4周）
→ ④ 审批通知 → ⑤ 领取外国人登录证（ARC）
```

### 境外申请（首次入境）

```
① 完成韩国法人设立 + 外国人投资登记
→ ② 前往驻本国韩国大使馆或领事馆提交签证申请
→ ③ 审核（通常需5~10个工作日）
→ ④ 签证签发 → ⑤ 入韩 → ⑥ 办理外国人登录手续
```

### 办理时限

- 境内：材料齐全情况下约2~4周
- 境外：约5~10个工作日（因领事馆而异）

> 如被要求补充材料，办理时限将相应延长。

## 6. 从D-8转换为F-2·F-5

D-8签证是通往长期居留及永久居留的重要通道之一。

### 转换F-2居住签证

- 持D-8签证期间，如满足**积分制居住（F-2-7）**评分条件，可申请转换
- 评分项目包括年龄、学历、韩语能力、收入、在韩居留年限等（通过标准：80分以上）
- 持F-2签证后，可从事的活动范围将大幅扩展

### 转换F-5永久居留签证

**F-5-5（外国人投资者永久居留）路径：**

| 条件 | 标准 |
|------|------|
| 持续投资 | 维持3亿韩元以上投资，或持续雇用2名以上韩国国民 |
| 居留期限 | 以D-8身份在韩连续居留5年以上 |
| 收入要求 | 达到或超过韩国人均GNI水平 |
| 法规遵守 | 居留期间无违反出入境法规记录 |

> **提示**：投资规模越大、创造本地就业越多，F-5审核越有优势。从法人成立初期起保持规范的税务和财务记录至关重要。

## 7. 常见问题

**Q1. 持D-8签证能否在其他公司兼职？**
不可以。D-8签证仅授权在所投资企业内从事经营管理职务，未经额外许可在其他公司就业或兼职属于违法行为。

**Q2. 设立法人之前能否先申请D-8签证？**
不可以。须先完成韩国法人设立及外国人投资登记，方可提交D-8签证申请。

**Q3. 配偶持F-3随行签证能否在韩工作？**
F-3签证原则上不允许就业。配偶如需工作，须另行申请工作签证（如E-7等）。

**Q4. D-8签证到期后该如何处理？**
须在签证到期前向出入境管理事务所申请延期。法人持续运营及投资额维持是获准续签的关键。

**Q5. 1亿韩元最低投资额是否须一次性缴纳？**
原则上须在提交签证申请时完成全额缴纳。如有分期投资计划，请事先咨询专业人士。

**Q6. 一人公司能否申请D-8签证？**
可以。只要完成1亿韩元以上的投资并以代表理事身份登记，即使是一人公司也可申请D-8签证。
